📺 Apps recomendadas + instalación paso a paso
IPTV Smarters

Recomendada para Smart TV, Android, TV Box y Fire TV.

  1. Busca IPTV Smarters en la tienda de apps.
  2. Abre la app y elige Xtream Codes API.
  3. Ingresa el Servidor, Usuario y Contraseña de esta hoja.
  4. Guarda y espera que cargue el contenido.
TiviMate

Ideal para Android TV y TV Box, especialmente para canales en vivo.

  1. Instala TiviMate desde Play Store.
  2. Selecciona Añadir lista.
  3. Elige URL M3U.
  4. Copia y pega el Link M3U de esta hoja.
XCIPTV

Muy buena opción para celular, tablet, Android TV y TV Box.

  1. Busca XCIPTV Player en Play Store.
  2. Elige conexión por Xtream Codes.
  3. Ingresa servidor, usuario y contraseña.
  4. Presiona iniciar sesión y espera la carga.
Smart IPTV

Opción para algunos modelos Smart TV. Puede requerir cargar lista por MAC.

  1. Instala Smart IPTV si aparece en tu TV.
  2. La app puede pedir cargar lista desde su web usando la MAC del televisor.
  3. Usa el Link M3U de esta hoja.
  4. Si se complica, contacta soporte PATAN TV.
🚀 Instalación rápida para no perderse
  1. Instala una app IPTV compatible.
  2. Si la app pregunta el tipo de acceso, elige Xtream Codes.
  3. Ingresa servidor, usuario y contraseña.
  4. Si la app pide lista, usa el Link M3U.
  5. Disfruta películas, canales y deportes como un verdadero Patán 😎.
